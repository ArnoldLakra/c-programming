## Operator Priority Order
* Highest Priority: *, /, %
* Middle Priority: +, -
* Lowest Priority: = (Assignment)
* Associativity: If two operators have the same priority (like * and /), C solves them from Left to Right
## Relational and Logocal operators
These are used to compare values and make decisions.
* True vs. False: In C, there is no "True" or "False" keyword. 1 represents True and 0 represents False
* Relational Operators: == (equal to), != (not equal to), >, <, >=, <=
* Logical Operators:
&& (AND): True only if both sides are true
|| (OR): True if at least one side is true
! (NOT): Flips the result (True becomes False, and vice versa)
