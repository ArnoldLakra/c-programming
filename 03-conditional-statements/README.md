# Conditional Statements in C

This section contains my practice with conditional
statements in C.

## Topics learned

- if
- if-else
- nested if
- ternary operator
- switch

## What I learned

### if-else
Used when a program needs to make a decision based
on whether a condition is true or false.

### Nested if
An if statement placed inside another if statement.

### Ternary operator
A shorter way to express a simple if-else condition.

### switch
Used when a program needs to choose between multiple
specific cases.
