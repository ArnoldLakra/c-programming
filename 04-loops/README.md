# Loops in C

This section contains my practice with:

- for loop
- while loop
- do-while loop
- break
- continue

## Problems solved

| Program | Concepts |
|---|---|
| Sum of N numbers | for, accumulator |
| Reverse number | while, arithmetic |
| Palindrome | while, conditions |
| Prime checker | loops, conditions |
| Fibonacci | loops, variables |
| Menu calculator | do-while, switch |
| Input validation | do-while, conditions |
| Skip multiples | continue |

## What I learned

Loops allow a program to repeatedly execute a block
of code while controlling when the repetition should
continue or stop.

I also learned that choosing the appropriate loop
depends on whether the number of iterations is known
beforehand and whether the loop must execute at least
once.
