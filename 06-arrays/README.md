# C Array Practice

This repository contains some of the array problems I've solved while learning C programming.

I'm using these programs to improve my problem-solving skills, understand how arrays work, and get better at writing logic on my own. These are small practice programs, but each one helped me learn something new.

## Programs

| Program | Description |
|---|---|
| **Array Analyzer** | Performs different operations on an array, such as finding important values and analyzing its elements. |
| **Array Rotation** | Rotates an array by a given number of positions. |
| **Element Frequency** | Counts how many times an element appears in an array. |
| **Equilibrium Index** | Finds an index where the sum of the elements on the left equals the sum of the elements on the right. |

## What I Learned

While solving these problems, I realized that writing a program is not just about knowing C syntax. The difficult part is often figuring out the logic and making sure it works in different situations.

Some of the things I practiced include:

- Accessing and processing array elements using indices.
- Using loops and conditions to solve array problems.
- Breaking a problem into smaller steps before writing code.
- Handling different inputs, including negative numbers, duplicate elements, and boundary cases where relevant.
- Finding and correcting logical errors when the output wasn't what I expected.
- Testing my solutions with different inputs instead of relying on a single successful run.

## Challenges I Faced

I sometimes struggled to figure out the correct logic, especially when a problem involved multiple conditions or required careful handling of array indices.

Instead of focusing only on getting the program to work, I practiced tracing the logic, testing different cases, identifying mistakes, and correcting them.

These problems helped me become more comfortable with arrays and taught me to approach programming problems more patiently.

## How to Run

You need a C compiler, such as GCC.

Compile a program:

```bash
gcc array-analyzer.c -o array-analyzer
```

Run it on Linux:

```bash
./array-analyzer
```

On Windows, run the generated executable:

```bash
array-analyzer.exe
```

Replace the filename with the program you want to run. The exact compilation command may vary depending on your folder structure and compiler setup.
